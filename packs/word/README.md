# Microsoft Word 常用排版与工具场景包 (Word Preset Pack)

本场景包专为 Microsoft Word 及各类办公文字编辑设计，提供高频排版与编辑动作快捷输入：

## 预设动作说明

1. **插入公式 (`Alt+=`)**：一键呼出 Word 官方公式编辑栏。
2. **插入日期与时间**：执行 `Alt+Shift+D` 插入当前系统日期，空格后追加 `Alt+Shift+T` 插入当前时间。
3. **行距设置**：通过功能区菜单快捷导航 `Alt` -> `H` -> `P` -> `G` 打开段落设置，接着 `Alt+N` 定位行距类型，`Alt+A` 定位行距值。
4. **仿宋_GB2312 字体**：通过 `Ctrl+D` 打开字体对话框，自动填入 `仿宋_GB2312` 并确认，快速切换公文标准字体。
5. **格式刷**：支持 `Ctrl+Shift+C` 复制格式与 `Ctrl+Shift+V` 粘贴格式。
6. **快速保存**：`Ctrl+S`。
7. **对齐方式**：`Ctrl+E` 居中对齐、`Ctrl+J` 两端对齐。
8. **版面控制**：`Ctrl+Enter` 插入分页符，`Ctrl+H` 查找替换。
